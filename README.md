# Unraid templates

Community Applications templates for [Bindery](https://github.com/vavallee/bindery), an open source ebook and audiobook automation server.

| App | Template |
|---|---|
| Bindery | [`templates/bindery.xml`](templates/bindery.xml) |

## Keeping in step with Bindery

The same template lives in the Bindery repo at `.github/unraid/bindery.xml`. When one changes, change the other. The two files are identical apart from `<TemplateURL>`, which points at its own raw file.
